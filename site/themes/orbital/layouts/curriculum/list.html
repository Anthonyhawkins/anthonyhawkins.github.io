Curriculum Overview

A self-paced Starlink Network and Topology study plan. Each module teaches the math you need, then applies it to Starlink-relevant systems with C++ and Python projects.

How to use this curriculum

Each module is self-contained: it teaches the math prerequisite, introduces the Starlink-relevant networking topic, then applies both through hands-on C++ and Python projects.

A long-running Starlink Network Toolkit grows across modules - each new module adds components that build on previous work.
