The Curriculum Overview

A 104-week (2-year) parallel-track study plan. Three tracks run simultaneously: mathematics, C++ programming, and space networking.

🔢 Math Track
💻 C++ Track
🛰️ Space Networking

How to use this curriculum

Select a module from the sidebar on the left to begin your journey. The modules start with foundational networking concepts mapped to the space environment, before moving into deeper orbital mechanics and protocol specifics.

Each module specifies whether mathematics prerequisites are required. Many pure protocol modules can be started immediately.
