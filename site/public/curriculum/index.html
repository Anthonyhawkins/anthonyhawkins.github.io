Curriculum Overview

A self-paced study plan for space networking. Each module teaches the math you need, then applies it to a space topic with C++ and Python projects.

How to use this curriculum

Each module is self-contained: it teaches the math prerequisite, introduces the space networking topic, then applies both through hands-on C++ and Python projects.

A long-running Space Network Toolkit grows across modules — each new module adds components that build on previous work.
